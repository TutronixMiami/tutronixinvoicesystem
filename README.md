# Tutronix Invoice System

This repository is linked to the Google Apps Script project:

`1UkRGE-_9i8eWqsHIgxT_TL2obyd-oIZX6e9g5pRU3anUDyV99CveDADZ`

Apps Script source files live in `src/` and are synchronized with Google Apps Script using [clasp](https://github.com/google/clasp).

## Sync commands

```sh
npx @google/clasp login
npx @google/clasp pull
npx @google/clasp push
```

Run these commands from the repository root. The `.clasp.json` file identifies the connected Apps Script project.
